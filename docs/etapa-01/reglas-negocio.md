Reglas de negocio 

R1: Cada huésped debe estar registrado con un DNI único. 

R2: Un huésped puede realizar una o varias reservas. 

R3: Cada reserva debe estar asociada obligatoriamente a un huésped. 

R4: Cada habitación debe tener un número único. 

R5: Cada habitación tiene una categoría, precio, y cantidad máxima de huéspedes. 

R6: Una habitación puede encontrarse disponible, ocupada, reservada o en mantenimiento. 

R7: Las habitaciones en mantenimiento no pueden ser reservadas. 

R8: Una habitación no puede tener dos reservas para las mismas fechas. 

R9: Toda reserva debe tener una fecha de entrada y una fecha de salida. 

R10: La fecha de salida debe ser posterior a la fecha de entrada. 

R11: Una reserva puede incluir una o más habitaciones. 

R12: Cada reserva debe tener un estado: pendiente, confirmada, cancelada o finalizada. 

R13: Al realizar el check-in se debe registrar la fecha y hora de ingreso. 

R14: Al realizar el check-out se debe registrar la fecha y hora de salida. 

R15: El check-out no puede realizarse antes del check-in. 

R16: Al realizar el check-out, la habitación vuelve a quedar disponible. 

R17: Cada pago debe registrar un importe, una fecha y un medio de pago. 

R18: El importe de un pago no puede ser negativo. 

R19: Una reserva puede tener uno o varios pagos. 

R20: Los medios de pago pueden ser efectivo, tarjeta o transferencia. 

R21: Una reserva se considera pagada cuando se abona el total correspondiente. 

R22: Los empleados del hotel pueden registrar y gestionar las reservas.
